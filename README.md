# Velzr Tweaks

Windows-Optimierung für Spiele. Hardwareabhängige Empfehlungen, jede Änderung wird vorher gesichert und lässt sich zurücknehmen, mit eingebauter FPS- und Ping-Messung.

## Download

Die neueste Version steht unter **[Releases](../../releases/latest)**: die Datei `Velzr-Tweaks-Setup-<Version>.exe` herunterladen und ausführen.

Hinweise zur Installation:
- Der Installer ist nicht digital signiert. Windows SmartScreen zeigt deshalb „Weitere Informationen“, dort „Trotzdem ausführen“ wählen.
- Die App braucht Administratorrechte, weil sie Systemeinstellungen ändert.
- Unterstützt Windows 10 und Windows 11.

## Das Wichtigste

- **Alles umkehrbar:** Vor jeder Änderung werden die Originalwerte gesichert. „Alles zurücknehmen“ stellt sie wieder her.
- **Für alle Spiele:** Die Empfehlungen passen zu deiner Hardware und wirken in jedem Spiel.
- **Nachprüfbar:** Mit der FPS-Messung siehst du vorher und nachher, was es gebracht hat. Es gibt keine Leistungsversprechen.
- **Privat:** Kein Konto, keine Telemetrie. Die App fragt einmal am Tag bei GitHub nach einer neuen Version (abschaltbar).
- **Kostenlos.**

Die App verändert keine Spieldateien und greift nicht in Anti-Cheat-Systeme oder den Netzwerkverkehr im Spiel ein.

## Updates

Neue Versionen erscheinen hier unter Releases. Die App zeigt oben „Update <Version>“, sobald eine neue verfügbar ist.
